## Description

Centralized storage repository for Soul:23 assets and shared data used across project repos. Hosts logos, media files, and reusable resources referenced via `raw.githubusercontent.com` URLs by other repositories in the organization.

Each project consumes assets from here through stable raw URLs, keeping visual identity and shared media decoupled from application code.
